# Muhammad Ibrahim Nizamani — Portfolio

Personal portfolio website of Muhammad Ibrahim Nizamani, a Senior Full Stack Engineer focused on building scalable backend systems, enterprise applications, and modern web products.

The portfolio showcases professional experience, selected projects, technical capabilities, and engineering work.

## Overview

This portfolio provides a concise view of:

- Professional experience across fintech, enterprise data, and SaaS
- Selected software projects and case studies
- Backend and full-stack engineering experience
- Technical interests and engineering work
- Resume and professional contact information

## Tech Stack

- Next.js — App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

The project intentionally keeps dependencies minimal and focuses on a clean, maintainable frontend architecture.

## Getting Started

Clone the repository:

    git clone https://github.com/mibrahimniz/portfolio.git
    cd portfolio

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.

## Available Scripts

### Development

    npm run dev

Starts the local development server.

### Lint

    npm run lint

Runs ESLint checks.

### Production Build

    npm run build

Creates an optimized production build.

### Production Server

    npm run start

Starts the production server after building the application.
